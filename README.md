# The Passport Page of a Country That Isn't There

This entry is a single self-contained Node program (`main.ts`, standard library only) that draws, entirely from code, an open passport spread for the invented Republic of Vessalia — a small coastal state whose capital is Port Anselm. The renderer is hand-rolled: a tiny rasterizer with 2× supersampling paints the cream paper, guilloche borders and spine shadow, while an embedded Hershey-style stroke font engraves every letter, from the bilingual data-page fields (English / Vessalian) and machine-readable zone at the foot of page 3, to the five immigration stamps on the visas page that quietly tell one traveller's story — Kordavia in June 2023, the Sarenne Federation that autumn, the Ostravia ferry the following January, and a departure from Meridia in September 2024. The holder, June Aurelia Marlowe, is reminded by the observations line that she may not photograph the Royal Lighthouse.
